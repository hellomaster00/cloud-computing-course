# Cloud Platform Recommendation Challenge

## Introduction

CloudNova Technologies has four clients with different business requirements. Each client needs a cloud platform that matches its budget, existing technologies, workload requirements, and future business goals. The following recommendations are based on the strengths and services offered by AWS, Microsoft Azure, and Google Cloud Platform.

---

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the startup because it provides a wide range of cloud services that can support a mobile application from development to production. The startup can begin with a smaller amount of infrastructure and increase its resources as the number of users grows. AWS also provides managed services that can reduce the amount of infrastructure the startup needs to maintain. This flexibility can help the company manage its resources while preparing for rapid growth.

### Recommended Services

* **Amazon EC2** – Provides virtual servers for running application workloads.
* **Amazon S3** – Provides scalable object storage for application files and data.
* **Amazon RDS** – Provides managed relational databases.
* **Amazon CloudFront** – Helps deliver application content to users with lower latency.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is recommended for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and identity services. The university can migrate selected services to the cloud while continuing to use its existing Microsoft environment. This makes Azure a practical choice for a hybrid cloud strategy.

### Recommended Services

* **Azure Virtual Machines** – Can run Windows Server and Linux workloads.
* **Microsoft Entra ID** – Provides cloud-based identity and access management.
* **Azure Blob Storage** – Provides storage for documents, backups, and other files.
* **Azure SQL Database** – Provides a managed relational database service.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud is recommended for the AI research company because it has strong capabilities in artificial intelligence, machine learning, data analytics, and scalable computing. The company can use cloud computing resources for demanding research and machine learning workloads. Google Cloud also provides tools that support the development, training, and deployment of AI applications. These capabilities make it a strong choice for an organization focused on AI research.

### Recommended Services

* **Compute Engine** – Provides virtual machines for high-performance computing workloads.
* **Vertex AI** – Provides tools for developing and deploying machine learning applications.
* **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized applications.
* **Cloud Storage** – Provides storage for datasets and research files.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the global e-commerce company because it provides global infrastructure and scalable cloud services. The company can distribute its applications across different geographic locations to improve availability and performance. AWS services can automatically scale resources according to changes in traffic and workload. This is especially useful for an e-commerce company that may experience very high traffic during sales and special events.

### Recommended Services

* **Amazon EC2** – Provides computing resources for web and application servers.
* **Elastic Load Balancing** – Distributes incoming traffic across multiple servers.
* **Amazon RDS** – Provides managed relational database capabilities.
* **Amazon CloudFront** – Delivers web content to users around the world.
* **Amazon S3** – Stores images, files, backups, and other application data.

---

# Recommendation Summary

| Client                       | Recommended Platform | Main Reason                                              |
| ---------------------------- | -------------------- | -------------------------------------------------------- |
| Client A – Startup           | AWS                  | Flexible and scalable services for a growing application |
| Client B – University        | Azure                | Strong integration with Microsoft technologies           |
| Client C – AI Research       | GCP                  | Strong AI, ML, data, and computing capabilities          |
| Client D – Global E-Commerce | AWS                  | Global infrastructure and scalable services              |

## Conclusion

The recommendations show that the best cloud provider depends on the client's specific requirements. AWS is a strong general-purpose platform for startups and global applications, Azure is highly suitable for organizations using Microsoft technologies, and Google Cloud is a strong choice for AI and machine learning workloads.
